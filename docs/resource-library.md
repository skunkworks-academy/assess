# Resource library

Use resources to support an outcome, not to collect certificates. For every resource you choose, decide **what you will make, test, explain, or improve** afterwards.

## Learn by doing

| Need | Starting point | Make it practical |
| --- | --- | --- |
| Digital and cloud skills | [Microsoft Learn](https://learn.microsoft.com/training/) | Complete one module, then document how its concept applies to a real workflow. |
| Web and technical foundations | [MDN Web Docs](https://developer.mozilla.org/) | Rebuild a small interface or explain one concept to a peer. |
| Data skills | [Kaggle Learn](https://www.kaggle.com/learn) | Analyse a small public dataset and write three evidence-based insights. |
| Project delivery | [Atlassian Team Playbook](https://www.atlassian.com/team-playbook) | Run one play with your team and record what changed. |
| Communication | [TED-Ed](https://ed.ted.com/) | Turn one lesson into a two-minute teaching explanation. |
| Free structured courses | [OpenLearn](https://www.open.edu/openlearn/) | Pair a short course with one workplace experiment. |

## Build professional habits

### The weekly learning note

Use this format after a learning session:

```text
I learned:
This matters because:
I will use it by:
The evidence I will collect is:
The person I will ask for feedback is:
```

### The feedback request

Be precise. Try: “I am working on making project updates more concise. Could you read this and tell me whether the decision, owner, and next step are clear in under one minute?”

### The evidence ladder

1. **Participation:** I attended, watched, or read.
2. **Understanding:** I can explain the idea in my own words.
3. **Application:** I used the idea in a real or simulated task.
4. **Improvement:** Feedback shows the outcome is clearer, faster, safer, or more useful.
5. **Contribution:** I helped another person apply it.

Aim for level 3 or higher.

## Useful tools

| Purpose | Tool pattern |
| --- | --- |
| Plan work | A simple weekly calendar plus a three-item priority list |
| Capture thinking | A Markdown note, notebook, or approved document workspace |
| Track actions | A lightweight Kanban board: To try / In progress / Evidence / Reviewed |
| Ask for input | A repeatable feedback message with one focused question |
| Present progress | A one-page update: goal, actions, evidence, next step |

## Curate your own library

Add a resource only after noting its title, what you will use it for, and the evidence it should help you create. Review your list monthly and remove resources that no longer serve the goal.
