# Nkateko Mtembi’s Individual Development Roadmap

## Suggested starting theme: digital solution building

Validate this theme in a kickoff conversation. The focus is on translating a need into a small, testable digital solution or workflow improvement.

### 30-day outcome

> I will improve digital solution building by designing and testing one small workflow, prototype, or automation. I will know it is useful when a user can complete the intended task more clearly or efficiently.

| Week | Practice | Evidence |
| --- | --- | --- |
| 1 | Identify a repetitive task or frustrating user journey. | Journey map and success measure. |
| 2 | Sketch a simple solution and test the assumption with one person. | Prototype or workflow diagram. |
| 3 | Build the smallest useful version. | Working demo or documented process. |
| 4 | Observe use, collect feedback, and prioritise one improvement. | Test notes and next iteration. |

## Weekly reflection

- What exact task is the solution helping someone complete?
- What is the smallest version that can be tested this week?
- What did a user do rather than say?

## Evidence checklist

- [ ] Problem and success measure
- [ ] Prototype or workflow sketch
- [ ] A test with a user or peer
- [ ] A working artefact or process guide
- [ ] A prioritised improvement
